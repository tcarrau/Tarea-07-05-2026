# Lista de recursos gratis para aprender a programar 
Dentro de este proyecto hay un monton de funetes(libros, tutoriales interactivos, etc) para aprender a programar 

### Objetivos del proyecto
- Motivar al estudio
- facilitar la busqueda de fuentes
- Hacer accesible la informacion para todos

### Instrucciones basicas de uso

1. Abrir la forma de aprendizaje que desees, libros, cursos, tutoriales, etc.
2. Luego apareceran una lista de todos los idiomas que hayan
3. Por cada idioma hay un monton de fuentes y lenguajes de programacion
4. Por ultimo solo tienes que empezar a aprender a programar asi de simple
